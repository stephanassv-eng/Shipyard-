# ShipYard

A product-catalog storefront built with Next.js + TypeScript.

- Live site: https://stephanassv-eng.github.io/Shipyard-/
- Lighthouse Performance: Pending (mobile)
## Run locally
npm install
npm run dev

## What it does
Browse a product grid and open a detail page for each product.
Optimized with next/image, next/font, lazy loading, and per-page metadata.
